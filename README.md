# 💰 Finans - Gestão Financeira Inteligente


O Finans é uma interface moderna e intuitiva de gestão financeira pessoal, desenvolvida para ajudar usuários a retomar o controle de sua vida econômica de forma simples e elegante.

📸 Screenshots


Interface limpa e focada na experiência do usuário (UX).
🌟 Destaques
⚡ Design Fluido: Construído 100% com Bootstrap, garantindo uma navegação rápida e componentes modernos.
📱 Totalmente Responsivo: Acesse do seu smartphone, tablet ou desktop sem perder nenhuma funcionalidade.
🎨 Interface Clean: Paleta de cores suave para evitar fadiga visual durante o planejamento financeiro.
📈 Foco em Conversão: Landing page otimizada com seções de funcionalidades, depoimentos e call-to-action.
🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as melhores práticas de desenvolvimento web front-end:
HTML5 - Estrutura semântica.
CSS3 - Estilizações personalizadas.
Bootstrap 5 - Framework principal para layout e componentes responsivos.
Google Fonts - Tipografia moderna.
Font Awesome - Ícones intuitivos.
